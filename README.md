# Website Toko Kecil-Kecilan

Proyek Ujian Tengah Semester (UTS) mata kuliah **Pemrograman Web Dasar** yang dibuat menggunakan HTML5, CSS3, dan JavaScript murni (Vanilla JavaScript).

Website ini dirancang untuk menampilkan informasi toko, profil toko, katalog produk, serta halaman kontak pelanggan dengan tampilan sederhana, menarik, dan responsif.

## 1. Struktur Folder

```text
TokoKita/
│
├── index.html          # Halaman Beranda
├── tentang.html        # Profil, visi, misi, dan pengelola
├── katalog.html       # Katalog 8 produk, pencarian, dan filter
├── kontak.html        # Informasi kontak dan formulir HTML5
│
├── css/
│   └── style.css      # Desain dan tampilan responsif
│
├── js/
│   └── script.js      # Menu hamburger, filter katalog,
│                      # dan validasi tambahan
│
├── img/               # Tempat menyimpan gambar lokal
│
└── README.md          # Dokumentasi proyek
```

## 2. Teknologi yang Digunakan

- **HTML5**: Membuat struktur halaman website.
- **CSS3**: Mengatur desain, warna, tata letak, dan responsivitas.
- **JavaScript**: Mengatur interaksi menu, pencarian, filter produk, dan validasi formulir.
- **Visual Studio Code**: Editor untuk menulis dan mengelola kode program.
- **Unsplash**: Sumber gambar yang digunakan dalam website.

## 3. Fitur Website

Website memiliki beberapa fitur utama:

1. Halaman beranda untuk menampilkan informasi toko.
2. Halaman tentang yang berisi profil, visi, misi, dan pengelola.
3. Katalog yang menampilkan 8 produk.
4. Fitur pencarian produk.
5. Fitur filter katalog berdasarkan kategori.
6. Tabel informasi jam operasional toko.
7. Menu navigasi hamburger.
8. Halaman kontak dan formulir HTML5.
9. Validasi formulir melalui browser.
10. Desain responsif untuk komputer dan perangkat HP.

## 4. Cara Menjalankan Website

Langkah-langkah menjalankan website:

1. Pastikan Visual Studio Code sudah terinstal.
2. Buka aplikasi Visual Studio Code.
3. Pilih menu **File → Open Folder**.
4. Pilih folder proyek `TokoKita`.
5. Pastikan seluruh file tersimpan sesuai struktur folder.
6. Buka file `index.html`.
7. Klik kanan pada file tersebut, kemudian pilih **Open with Live Server** jika ekstensi Live Server sudah terpasang.
8. Website akan terbuka secara otomatis melalui browser.

Website juga dapat dijalankan dengan membuka file `index.html` secara langsung melalui browser.

**Catatan:** Foto pada website saat ini menggunakan Unsplash sehingga koneksi internet diperlukan agar gambar dapat ditampilkan.

## 6. Keterbatasan Website

Website ini masih menggunakan teknologi HTML, CSS, dan JavaScript murni sehingga memiliki beberapa keterbatasan:

- Belum menggunakan database.
- Belum memiliki sistem login admin.
- Data produk belum terhubung dengan database.
- Formulir kontak hanya divalidasi melalui browser.
- Formulir belum dapat mengirimkan data ke server.
- Foto menggunakan Unsplash sehingga membutuhkan koneksi internet.
